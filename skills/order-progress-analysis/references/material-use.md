# 物料使用率分析模块（MU）

## 概述
本模块用于分析订单生产过程中的物料使用情况，计算材料利用率（Material Utilization），识别织、染、缝各生产环节的损耗，分析投料控制情况。

## 核心概念

**材料利用率（MU）** = 成品入仓数 / 订单应织数

即产出与投料的比例，衡量原材料被有效利用的程度：

```
材料利用率 = (单位产品中包含的材料净重量 / 单位产品耗用材料总重量) × 100%
```

MU 越接近 100% 表示材料利用越高效。超过 100% 通常表示超产，低于合理范围则表示损耗过大。

### 调用示例

参数以 JSON 传入：

```jsonc
// 1. 查询指定订单的物料使用率（必须提供订单号）
{ "orderCode": "<订单号>" }

// 2. 查询多个订单（订单号用逗号分隔，中英文逗号均可）
{ "orderCode": "订单号1,订单号2" }

// 3. 查询越南组织的订单
{ "orderCode": "<订单号>", "org": "越南" }
```

### 参数说明

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `orderCode` | ✅ | - | 订单号，多个订单号用逗号分隔（**必须提供**） |
| `org` | ❌ | 义乌 | 组织信息，可选值：`义乌`、`越南` |

### 模块注意事项

- **必须提供订单号**（`orderCode` 参数），否则查询会报错
- 默认查询义乌组织，如需查询越南组织需传 `org: "越南"`

## 生产流程与物料流转

订单生产的物料流转链路：

```
纱线入仓 → 织造 → 染色(发染+回染) → 分检 → 裁剪(修剪) → 调度仓 → 车缝 → 走货
```

### 关键流转节点

1. **织造**：纱线 → 布片
   - 投入：纱线入仓数（kg）
   - 产出：实织数（件）
   - 损耗：坏片数量

2. **染色**：布片 → 染色布片
   - 投入：发染数
   - 产出：回染数
   - 损耗：染色次品数

3. **分检**：染色布片 → 合格布片
   - 投入：分检数
   - 产出：合格数（分检数 - 分检次品数）
   - 损耗：分检次品数

4. **裁剪**：布片 → 裁片
   - 投入：修剪数
   - 产出：裁片数 × 比例系数

5. **车缝**：裁片 → 成品
   - 投入：车缝领料数
   - 产出：车缝完成数
   - 损耗：车缝次品数

6. **出货**：成品 → 客户
   - 走货数：已出货数量

## 分析流程

### 第一步：获取当前时间

```bash
date "+%Y-%m-%d %H:%M:%S"
```

### 第二步：获取物料使用率数据

优先在界面常规报表查询 `101200.订单MU分析`（填写订单号条件）；界面不可用时调用 `order_mu` 工具获取数据（`orderCode` 为订单号）：

```jsonc
{ "orderCode": "<订单号>" }
```

如遇到权限相关错误（见 SKILL.md 权限错误处理章节），**立即停止**。

### 第三步：解析与分析

1. **解析数据**：将界面报表或 MCP 返回的数据解析为结构化数据，记录原始数据
2. **计算各环节损耗率**：分析织造、染色、分检、车缝各环节的损耗情况
3. **分析实织比例**：判断是否超产或投料失控
4. **评估 MU 指标**：计算和评估整体材料利用率
5. **识别异常**：找出损耗过大、超产、投料失控等隐患
6. **输出报告**：以结构化方式呈现分析结果，在报告中明确标注分析基准时间

## 分析维度

### 材料利用率评估

- **整体 MU**：直接读取数据中的 MU 字段
- **MU 合理性判断**：
  - MU 接近 100%：材料利用高效
  - MU > 100%：超产，需关注物料供应平衡
  - MU < 80%：损耗过大，需定位损耗环节
  - MU < 50%：严重损耗，需重点关注

### 织造环节分析

- **实织比例**：实织数 / 应织数
  - 实织比例 > 120%：严重超产，投料控制可能失效
  - 实织比例 < 90%：生产不足，可能影响交期
  - 实织比例 90%-110%：合理范围
- **坏片比例**：坏片数量 / 实织数
  - 坏片比例 > 5%：织造质量问题，需排查设备或工艺
  - 坏片比例 < 2%：织造质量良好

### 染色环节分析

- **染色流转**：发染数 vs 回染数
  - 发染数 = 回染数：正常流转
  - 发染数 > 回染数：存在滞留或损耗
- **染色次品比例**：
  - 染色次品比例 > 3%：染色质量问题，需排查染料或工艺
  - 染色次品比例 < 1%：染色质量良好

### 分检环节分析

- **分检次品比例**：
  - 分检次品比例 > 3%：质量管控不足，需加强过程控制
  - 分检次品比例 < 1.5%：质量管控良好

### 车缝环节分析

- **车缝流转**：车缝领料数 vs 车缝完成数
  - 领料数 > 完成数：存在在制品或损耗
  - 领料数 = 完成数：正常流转
- **车缝次品数**：
  - 车缝次品比例 = 车缝次品数 / 车缝完成数
  - 车缝次品比例 > 2%：车缝质量问题，需排查工艺或人员技能

### 投料控制分析

- **纱线投入合理性**：纱线入仓数（kg）vs 应织数 × 单位克重
  - 投入 > 理论需求 × 1.1：过度投料
  - 投入 < 理论需求 × 0.9：投料不足，可能影响生产
- **实织数 vs 应织数**：
  - 实织数远超应织数：可能投料失控或订单数据异常
  - 实织数接近应织数：投料控制良好

### 隐患识别

重点关注以下风险信号：

#### 损耗过高
- 某环节次品比例 > 3%
- 坏片比例 > 5%
- 各环节累计损耗导致 MU 偏低

#### 超产失控
- 实织比例 > 150%：严重超产
- 实织比例 > 120%：明显超产
- 需关注是否影响物料供应平衡和成本

#### 投料控制问题
- 纱线投入量与理论需求差异过大
- 实织数远超应织数，投料控制可能失效

#### 环节失衡
- 前后环节物料数量差异异常（如发染数远小于实织数）
- 在制品存量过大，物料流转不畅

#### 质量异常
- 多个环节次品比例同时偏高
- 次品数累计影响有效产出

#### 数据异常
- 关键字段为空或为 0（如应织数为 0、实织数为 0）
- 比例计算异常（如分母为 0）
