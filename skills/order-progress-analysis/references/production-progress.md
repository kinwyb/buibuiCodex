# 生产进度分析模块

## 概述
本模块用于分析生产系统中订单的生产进度，识别生产隐患和异常。

## 数据获取

优先通过 `ui-operation` 从「常规报表」（`view: V0018_V0112`）查询对应报表；界面不可用时再用 `boda` MCP 的 **`order_process`** 工具兜底。完整流程见 SKILL.md 的「数据获取方式（界面优先，MCP 兜底）」。

### 优先：界面常规报表

| 查询内容 | 报表编号与名称 | `reports.find` 关键字 |
|----------|----------------|-----------------------|
| 汇总数据 | `104740.订单汇总表-未完成订单` | `订单汇总表-未完成订单` |
| 工序级明细 | `104110.订单工序进度查询` | `订单工序进度查询` |

- 汇总与明细是**两张不同的报表**：`detail: false` 对应 `104740`，`detail: true` 对应 `104110`
- 订单号条件在报表 `args` 中按名称「订单号」对应，组织条件按名称「组织」对应；具体字段 id 以 `reports.find` 返回的 `args[].field` 为准
- 两张报表都查时，分别执行 `report.query`，每次都要用户确认

### 兜底：MCP 工具

界面不可用时，使用 `boda` MCP 服务的 **`order_process`** 工具查询订单生产进度数据。

### 调用示例

参数以 JSON 传入：

```jsonc
// 1. 查询全部未完成订单进度汇总
{}

// 2. 按订单号筛选汇总数据（多个订单号用逗号分隔，中英文逗号均可）
{ "orderCode": "订单号1,订单号2" }

// 3. 查询指定订单的工序级明细（必须同时提供 orderCode）
{ "orderCode": "<订单号>", "detail": true }

// 4. 查询越南组织的订单
{ "orderCode": "<订单号>", "org": "越南" }
```

### 参数说明

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `orderCode` | ❌ | - | 订单号，多个订单号用逗号分隔 |
| `detail` | ❌ | false | 是否返回工序级明细数据（必须同时提供 `orderCode`） |
| `org` | ❌ | 义乌 | 组织信息，可选值：`义乌`、`越南` |

### 输出格式

工具返回 **JSON** 格式，结构如下：

```json
{
  "columns": ["字段名1", "字段名2", ...],
  "data": [
    {"字段名1": "值1", "字段名2": "值2", ...},
    ...
  ]
}
```

- `columns`：字段名列表，定义数据含义及读取顺序
- `data`：数据数组，每个元素为一条订单记录（键值对）
- 日期字段格式为 `YYYY-MM-DD`（已自动去除 `00:00:00` 后缀）
- 空字符串 `""` 表示该字段无数据

### 模块注意事项

- 如果用户提供了具体订单号，优先使用 `orderCode` 参数过滤查询，减少数据量
- **明细查询（`detail: true`）必须同时提供 `orderCode` 参数（订单号），否则会报错**
- 默认查询义乌组织，如需查询越南组织需传 `org: "越南"`
- 汇总查询返回全部未完成订单数据量可能较大，建议用 `orderCode` 缩小范围

## 生产流程

订单生产严格按以下 6 个工序顺序流转：
```
织造 → 发染 → 回染(染色) → 分检 → 缝制 → 成品
```

## 数据字段说明

| **染色进度** | 发染完成数、发染未完成数、发染结束时间、染色完成数、染色未完成数、染色开始时间、染色结束时间、染色克重、未染色重量(KG)、毛坯存货 | 染色环节完成情况 |
| **分检进度** | 分检完成数、分检未完成数、分检存货、分检结束日期、次品数、二次派工数 | 分检环节完成情况 |

### 明细数据（加 `-d` 参数）

按**颜色+尺码**维度展开，主要字段：

| 分类 | 字段 | 说明 |
|------|------|------|
| **基本信息** | 部门、订单号、织造物料、织造物料名称、织造颜色、织造尺码 | 产品维度展开信息 |
| **计划与产出** | 计划数、出货数、抛量数、抛量比例、船样数 | 计划和实际产出对比 |
| **织造** | 织造完成数 | 该颜色尺码的织造完成量 |
| **染色** | 发染数、回染数、排回染数 | 染色流转数据 |
| **分检** | 次品数、二次派工数、少数、比例、分检结单(true/false)、分检正品结存 | 分检质量和结单状态 |
| **裁片超市** | 计划裁片超市数、裁片超市小包数、裁片超市入库数、裁片超市出库数、裁片超市余数 | 裁片中转管理 |
| **备料仓** | 备料仓入库数、备料仓出库数、备料仓存数、备料仓未出库数 | 备料仓流转 |

| **今日产量** | 以 `今日_` 开头的各工序字段 | 当日各工序完成数（用于判断产线是否在生产） |
| **成品** | 手工成品检验数、手工成箱数、成品包装、包装在制品、入包装数、挂衣架 | 成品包装阶段 |

## 各工序关键指标

**1. 织造**：织造完成数、织造未完成数、织造结束时间(计划)、织造工时、毛坯存货、未织造工时(h)、织造产地
**2. 发染**：发染完成数、发染未完成数、发染结束时间(计划)、未染色重量(KG)、染色克重
**3. 回染(染色)**：染色完成数、染色未完成数、染色结束时间(计划)、染色开始时间
**4. 分检**：分检完成数、分检未完成数、分检结束日期(计划)、分检存货
**5. 缝制**：缝制完成数、缝制未完成数、缝制结束时间(计划)、缝制工时、未缝制工时(h)、缝制主工序、缝制产线分组
**6. 成品**：成品入库数、成品未入库数、成品库存数、手工成箱完成数、手工成箱未完成数、销售出库数

## 工序间数据依赖关系

- 后工序完成数 ≤ 前工序完成数（否则数据异常）
- 后工序计划结束时间 ≥ 前工序计划结束时间（否则时间倒挂）
- 前工序未完成数 = 后工序可能的原料缺口

## 计划时间顺序校验

正常情况下，各工序计划结束时间应满足：
```
织造结束时间 ≤ 发染结束时间 ≤ 染色结束时间 ≤ 分检结束日期 ≤ 缝制结束时间 ≤ 生产入库期
```

## 分析流程

### 第一步：获取汇总数据

优先在界面常规报表查询 `104740.订单汇总表-未完成订单`（按需填写订单号条件）；界面不可用时调用 `order_process` 工具查询汇总数据（`orderCode` 为订单号，可省略）：

```jsonc
{ "orderCode": "<订单号>" }
```

### 第二步：按需获取明细数据（仅在用户明确要求时使用）
**除非用户明确要求查询明细，否则默认只查询汇总数据。** 以下关键词表示用户需要明细数据：**工序进度、颜色、尺码、每日产量、今日产量**。

界面模式下改查 `104110.订单工序进度查询`；MCP 模式下传 `detail: true`：

```jsonc
{ "orderCode": "<订单号>", "detail": true }
```

### 第三步：解析与分析

1. **解析数据**：将界面报表或 MCP 返回的数据解析为结构化数据，记录原始数据
2. **按工序顺序分析**：以基准时间为基准，按"织造→发染→回染→分检→缝制→成品"顺序逐一检查每个订单的各工序进度。**工序完成状态以完成数量判断，不以计划结束时间判断**
3. **前后工序关联检查**：校验工序间数据依赖关系和计划时间顺序
4. **识别隐患**：找出可能存在的风险和异常
5. **输出报告**：以结构化方式呈现分析结果，在报告中明确标注分析基准时间

## 分析维度

### 单工序进度评估
对每个订单的每个工序分别检查：
- 完成数 / 数量的完成比例
- 未完成数的含义：正数=剩余量、0=恰好完成、负数=超产数量
- 当前时间与计划结束时间对比：已超期/未超期（注意：超期不代表已完成，仅表示进度压力）
- 当前计划结束时间与生产入库期对比：剩余天数是否充足

### 前后工序关联分析
- 后工序完成数是否超过前工序完成数（违反则为异常）
- 前工序已完成但后工序未开始（可能存在瓶颈或排产问题）
- 前工序未完成数较大导致后工序原料不足（供应链断裂风险）

### 隐患识别

#### 交期风险
- 当前时间已超过某工序计划结束时间但该工序未完成数仍较大
- 生产入库期已临近或已过，但缝制完成数远低于订单数量
- 走货月份已到但成品入库数极低
- 未缝制工时(h) 数值很大，表示剩余缝制工作量大

#### 入库风险
- 按当前各工序进度推算，无法在生产入库期前完成成品入库

#### 工序瓶颈
- 某工序完成数远低于前工序完成数，大量积压
- 明细数据中关键工序的「今日_」产量为 0（表示当日未生产）
- 缝制产线分组/组别为空或产能分散

#### 数据倒挂
- 后工序完成数超过前工序完成数，或计划结束时间倒挂

#### 超产关注
- 未完成数出现较大负数，可能影响物料供应或排产平衡

#### 停滞异常
- 前工序已有大量完成数，但后工序完成数长时间无增长
- 明细中发染数 > 0 但回染数为 0（可能染色环节停滞）

#### 质量异常
- 次品数或二次派工数偏高
- 分检结单为 false 且比例偏低
- 缝制成品疵品/多数/少数有值

#### 物料风险
- 原料到仓期或辅料到仓期为空（物料可能未到位）
- 毛坯存货为负数（库存不足）
- 备料仓未出库数 > 0（有备料未发出）

#### 产能风险
- 未织造工时(h)、未缝制工时(h)等工时数值过大，剩余时间内难以完成

#### 集中风险
- 大量订单集中在同一工序阶段，可能造成产能瓶颈
