 # 毛利率明细分析 — 功能需求 Prompt 文档

 > 本文档从现有 `finance` 技能的「毛利率明细分析」模块中提取完整功能需求。
 > 当数据源发生变化时，可直接基于本 Prompt 重新生成技能模块（references、scripts、SKILL.md 等），
 > 只需替换「数据源适配层」中的字段映射和取数工具（MCP 工具）即可。

 ---

 ## 一、模块定位

 本模块用于分析订单毛利率的**成本构成明细**。在订单整体毛利率分析基础上，继续拆解：

 - 单位成本结构
 - 投入产出链路（包装 → 缝制 → 染色 → 织造 → 原材料）
 - 存货价格流水

 最终定位毛利率异常的具体原因，输出可追溯到原始数据的分析报告。

 **触发条件**（仅在用户明确要求以下内容时进入本模块）：

 - 成本组成、成本明细、毛利率明细、单位成本结构
 - 投入产出耗量、材料价格影响、存货价格流水
 - 包装/缝制/染色/织造/原材料等生产环节成本拆分
 - 阶段净成本、成本项目标准占比、订单报价明细测算

 如果用户只是要求分析毛利率、成本、利润、亏损、低毛利或报价风险，优先使用「订单毛利率分析」模块。

 ## 三、核心业务口径

 ### 3.1 成本追溯链路

 服装制造的成本构成遵循多层半成品流转结构。以包装成品物料编码为起点查询投入产出，一次返回所有生产阶段明细：

 ```
 包装成品 (单位成本.物料编码；投入产出查询入参)
   |
   +- 包装阶段 (剔除缝制成品)
   |
   +- 缝制阶段 (剔除毛坯)
   |
   +- 染色阶段 (剔除白坯)
   |
   +- 织造阶段 (剔除白坯等下一层半成品)
   |
   +- 原材料阶段 (核算要素名称=原料，无下一层)
   |
   +- 存货明细 (对异常材料编码查价格流水)
 ```

 `所属工段` 标准取值：`包装 / 缝制 / 染色 / 织造 / 原材料`。原料单列"原材料"工段，不混入织造。

 ### 3.2 阶段净成本口径

 成本结构分析必须按**单阶段净成本**归集，不把下一层半成品重复计入当前工段。

 | 阶段 | 需要剔除的下一层成本 | 本阶段应计入的成本 |
 |------|---------------------|-------------------|
 | 包装 | 缝制成品 | 包装辅料、公共包装辅料、包装直接人工、制造费用、加工费等 |
 | 缝制 | 毛坯 | 缝制辅料、缝制人工、缝制制造费用、缝制加工费、委外加工费等 |
 | 染色 | 白坯 | 染色加工费、染色人工、染色制造费用、染化料等 |
 | 织造 | 白坯/毛坯/下一层半成品 | 织造人工、织造制造费用、织造加工费等 |
 | 原材料 | 无下一层 | 原料、纱线、其他原料等成本本身 |

 公式：`本阶段净成本 = 本层投入产出金额合计 - 下一层半成品/原料金额`

 报告必须同时列出：本层投入产出总额、剔除的下一层金额、本阶段净成本、本阶段净成本占订单完工成本比例。

 ### 3.3 成本结构占比口径

 **严禁使用单位成本字段反推成本结构占比**。单位成本仅返回包装层自身字段，下游工段金额全部合并在"未分类"中。

 正确做法是基于**投入产出数据逐级展开**：

 1. 以包装成品物料编码为起点，沿 carry 链向下游追踪
 2. 每个工段按 `上级 carry 金额 / 本工段 stage_total` 计算折算系数
 3. **carry 行（下一层半成品）不计入当前阶段成本项目**
 4. 非 carry 行按 `核算要素名称` 映射到五大成本项目
 5. 链路断裂时，缺失工段跳过，下游使用 `last_scale`（最后一个有效折算系数）兜底
 6. **未追溯半成品 = 完工成本 - 已分类合计**

 五大成本项目之和 + 未追溯半成品 = 完工成本（即 100%）。

 ### 3.4 成本项目标准占比

 | 成本项目 | 预设标准占比 | 正常区间 | 计算逻辑 |
 |----------|-------------|----------|----------|
 | 原材料 | 30% | 25%-35% | 原材料阶段金额 + 织造阶段原料类金额，按折算系数累加 |
 | 辅料 | 10% | 5%-15% | 包装辅料 + 缝制辅料 + 公共辅料等，按折算系数累加 |
 | 直接人工 | 35% | 30%-40% | 各阶段直接人工/间接人工/福利费/五险一金/劳务费 |
 | 制造费用 | 20% | 15%-25% | 各阶段折旧费/水电费/修理费/低值易耗品/汇总其他 |
 | 外协加工费 | 5% | 0%-10% | 各阶段加工费/委外加工费 |

 ### 3.5 核算要素 → 成本项目映射表

 | 成本项目 | 核算要素名称关键词 |
 |----------|-------------------|
 | 原材料 | 原料、纱线、其他原料；`所属工段=原材料` 的行全部归入 |
 | 辅料 | 包装辅料、缝制辅料、公共缝制辅料、公共包装辅料 |
 | 直接人工 | 直接人工、间接人工、福利费、五险一金、劳务费 |
 | 制造费用 | 折旧费、水费、电费、水电费、修理费、低值易耗品领用摊销、汇总其他 |
 | 外协加工费 | 加工费、委外加工费 |
 | 半成品链路(carry) | 缝制成品、毛坯、白坯、坯布（不计入成本项目） |

 ### 3.6 折算率计算规则

 #### 正常链路

 | 阶段 | 折算系数公式 |
 |------|-------------|
 | 包装 | 1.0000（根节点） |
 | 缝制 | 包装中缝制成品 carry 金额 / 缝制工段投入产出总额 |
 | 染色 | 缝制中毛坯 carry 金额 / 染色工段投入产出总额 |
 | 织造 | 染色中白坯 carry 金额 / 织造工段投入产出总额 |
 | 原材料 | 织造中白坯/毛坯 carry 金额 / 原材料工段投入产出总额 |

 折算率含义：上级包装成品对下游各工段成本的"认领比例"。

 #### 链路断裂时

 上游工段缺失时，断裂点下游所有工段统一使用 `last_scale` 兜底：

 ```
 last_scale = 断裂前最后一个有效折算系数
 下游工段折算后金额 = 下游工段 stage_total × last_scale
 ```

 | 缺失阶段 | 直接取值的下一层 | 受影响下游 | 兜底机制 |
 |----------|-----------------|-----------|----------|
 | 染色 | 织造 | 原材料 | 织造标"直接取值"，折算系数=缝制折算率；原材料按 last_scale 兜底 |
 | 缝制 | 染色 | 织造、原材料 | 染色标"直接取值"；织造/原材料按 last_scale 兜底 |
 | 织造 | 原材料 | - | 原材料标"直接取值" |
 | 包装 | - | 全部下游 | 所有下游按 last_scale 兜底 |

 生产阶段取数状态分四种：

 | 状态 | 含义 |
 |------|------|
 | 已取到 | 有数据，能正常按父级折算 |
 | 直接取值 | 有数据，但直接父级未取到，折算系数=last_scale |
 | 未取到 | 无数据，可能为委外生产或报表未返回 |
 | 已取到(last_scale兜底) | 有数据，但上游链路断裂，按 last_scale 兜底 |

 ### 3.7 成品单价口径

 阶段成品单价用于查看产品做到该阶段时的综合单价（含子工段成本），不用于成本项目剔除。

 当上级领用金额与本阶段明细总额不一致时：
 - 成品单价分析以本阶段明细为准
 - 同时展示上级领用金额、上级领用单价和差异金额
 - 成本项目标准占比按上级实际领用金额折算，确保成本闭合

 ## 四、分析主流程

 1. 用单位成本按会计区间或订单号取数，校验订单收入、成本、单位成本、毛利和毛利率
 2. 用包装成品的物料编码查询一次投入产出，获取包装/缝制/染色/织造/原材料等工段明细
 3. 按生产阶段分组，分别计算各阶段净成本
 4. 检查链路完整性：若某上游工段缺失，对下游工段改用"直接取值"口径
 5. 输出链路追溯图（树形/链式结构），每个节点标注状态、物料编码、carry 指向、金额和折算系数
 6. 按阶段净成本口径累计成本项目标准占比
 7. 对成本占比异常、单价异常或金额占比高的材料，查询存货明细价格流水
 8. 用内置脚本或可靠计算工具完成阶段净成本、成本项目标准占比、异常金额和毛利率影响测算
 9. 按报告模板输出最终分析报告

 ### 取数顺序

 1. 先查单位成本 → 获取包装成品物料编码、完工成本、完工产量、销售金额、毛利率
 2. 用包装成品物料编码查一次投入产出 → 返回所有生产阶段明细
 3. 检查生产阶段完整性（包装→缝制→染色→织造→原材料）
 4. 识别链路断裂，标记未取到/直接取值工段
 5. 按生产阶段分组计算阶段净成本
 6. 对异常材料查存货明细价格流水

 ## 五、异常识别规则

 ### 5.1 亏损/低毛利订单

 | 类型 | 识别标准 | 常见原因 |
 |------|----------|----------|
 | 亏损订单 | 毛利率 < 0 | 原材料涨价未调价、订单量过小、工艺复杂、外协费高、定价问题 |
 | 低毛利订单 | 毛利率 0%~10% | 半成品成本高、辅料/人工/制造费用压缩空间不足 |

 ### 5.2 成本结构异常（超阈值必须标记）

 - 原材料 > 35%：原料涨价或耗量超耗
 - 辅料 > 15%：包装冗余或辅料单价偏高
 - 直接人工 > 40%：工序工价偏高或产量不足
 - 制造费用 > 25%：分摊口径异常或产量规模不足
 - 外协加工费 > 10%：外发价格偏高或自制/外协边界不合理

 ### 5.3 投入产出异常

 - 单材料占完工成本 > 20%
 - 同一材料不同期间单价差异大
 - 实际耗量 > BOM 定额 × 完工产量
 - 负数量/负金额（数据异常或红字冲销）
 - 同一材料多行价格差异大

 ### 5.4 存货价格异常

 - 单价高于同期间均价，或达同期均价 2 倍以上
 - 金额大但数量小（可能计量单位错误）
 - 单据类型异常集中
 - 月度加权均价波动大

 ### 5.5 毛利率波动

 - 同一物料在不同订单间毛利率差异 > 10 个百分点
 - 同一客户不同期间毛利率波动明显

 ### 5.6 数据一致性校验

 - 毛利 ≈ 销售无税金额 - 完工成本
 - 毛利率 ≈ 毛利 / 销售无税金额
 - 单位成本 ≈ 完工成本 / 完工产量
 - 投入产出金额合计应与单位成本对应字段可解释
 - 存货明细金额合计 ≈ 主数量 × 单价

 发现不一致时标注原因：四舍五入误差、数据导出问题、口径差异等。

 ### 5.7 毛利率分级评估

 | 毛利率范围 | 评级 | 说明 |
 |-----------|------|------|
 | >= 30% | 优秀 | 利润空间充足 |
 | 20% ~ 30% | 良好 | 利润水平正常 |
 | 10% ~ 20% | 一般 | 利润空间偏紧，需关注成本控制 |
 | 0% ~ 10% | 预警 | 利润较低，建议分析成本构成 |
 | < 0% | 异常 | 亏损订单，需重点排查原因 |

 ---

 ## 六、基础计算公式

 ```
 毛利 = 销售无税金额 - 完工成本
 毛利率 = 毛利 / 销售无税金额
 单位成本 = 完工成本 / 完工产量
 成本项目占比 = 成本项目金额 / 订单完工成本
 投入产出单位耗量 = 投入产出数量 / 上层完工产量
 投入产出单位成本 = 投入产出金额 / 上层完工产量
 存货价格影响 = 当前材料单价 vs 同期间均价/最高价/最低价/上期可比单价
 价格波动影响金额 = (实际单价 - 均价) × 消耗数量
 ```

 数值处理：优先使用脚本或工具验证；报告中保留足够小数位并标明四舍五入展示。

 ## 九、强制规则

 ### 9.1 数据真实性

 - 所有分析结论必须严格基于取数工具（MCP 工具）返回的实际数据
 - 严禁编造数据、推测缺失字段、对不存在的字段进行分析
 - 查询无结果时明确告知用户
 - 字段不存在时必须明确说明，列出实际可用字段

 ### 9.2 数字计算精度

 - 所有加减乘除计算必须逐步精确完成，不可跳步
 - 引用原始数据中的数值必须与返回结果完全一致，逐字核对
 - 如需估算，数值前必须标注「约」「≈」「估算」
 - 涉及金额、毛利率等关键指标，优先使用工具（bc、awk、Python）验证

 ### 9.3 跨时间对比表述

 对比不同时间段数据时，始终按「早期 → 后期」顺序描述：

 - ✅ "从3月的 3.66% 提升至4月的 17.83%，毛利率改善 14.17 个百分点。"
 - ❌ "4月毛利率 17.83%，远高于3月的 3.66%。"（倒叙，禁止）

 ### 9.4 权限错误处理

 遇到权限相关错误（`无权操作`/`权限不足`/`unauthorized`/`forbidden`/`token 失败`）时：
 - 立即停止，禁止重试
 - 将错误信息原样返回
 - 提示用户检查 MCP 服务授权状态与账号数据权限

 ### 9.5 表达规范

 - 正文使用中文业务名称（单位成本、投入产出、存货明细），禁止暴露 MCP 工具名
 - 建议必须绑定异常项和数据证据
 - 无对比数据时不生成对比结论
 - 成本追溯终止条件（空数据、缺字段、缺阶段、循环引用等）必须在报告中标记影响

 ## 十、数据源变更指南

 当数据源发生变化时，按以下步骤适配：

 1. **替换取数工具**：修改第二章的取数工具和参数
 2. **更新字段映射**：根据新数据源的 `columns` 更新字段参考表
 3. **调整核算要素映射**：如果新数据源的分类名称不同，更新 3.5 节的映射表
 4. **调整工段分类**：如果新数据源的生产阶段不同，更新 3.1 节的链路结构和 3.2 节的 carry 规则
 5. **调整阈值**：如果行业标准变化，更新 3.4 节的标准占比和 5.2 节的异常阈值
 6. **重新生成脚本**：基于更新后的映射表重新生成分析脚本

 第三章到第九章的分析逻辑、计算规则、报告模板和强制规则保持不变，它们描述的是业务分析方法论，与具体数据源无关。
