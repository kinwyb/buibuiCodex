## 概述

本模块用于分析订单毛利率的成本构成明细，在订单整体毛利率分析基础上，继续拆解单位成本、投入产出链路和存货价格流水，定位毛利率异常的具体原因。

与 `order-gross-margin.md` 的关系：

- `order-gross-margin.md` 关注订单整体毛利率：盈利/亏损分布、毛利率分级、客户/物料汇总。
- 本模块关注成本明细追溯：用包装成品物料一次查询投入产出，按返回数据中的生产阶段归类拆分包装、缝制、染色、织造，再结合存货明细分析价格波动，定位成本偏高的具体环节。

面向用户输出报告时，必须使用中文业务名称，不要直接暴露工具名：

| 工具/文件名术语 | 对用户输出名称 |
|----------------|----------------|
| `finance_analysis_unitCostStructure`（单位成本结构） | 单位成本 |
| `finance_analysis_inputOutput`（投入产出表） | 投入产出 |
| `finance_analysis_inventoryLedger`（存货明细帐） | 存货明细 |
| `finance_analysis`（综合毛利率查询） | 订单毛利率 |

调用工具时可以保留工具名（那是实际调用语法）；分析报告、结论、异常说明、数据缺失说明必须使用中文名称。

## 何时使用

只在用户明确要求以下内容时使用本模块：

- 成本组成、成本明细、毛利率明细、单位成本结构
- 投入产出耗量、材料价格影响、存货价格流水
- 包装、缝制、染色、织造、原料等生产环节成本拆分
- 阶段净成本、成本项目标准占比、订单报价明细测算

如果用户只是要求分析毛利率、成本、利润、亏损、低毛利或报价风险，优先使用订单毛利率分析；只有用户明确要求继续下钻成本组成时，才进入本模块。

## 核心业务口径

### 成本追溯链路

服装制造的成本构成遵循多层半成品流转结构。投入产出查询传入包装成品物料编码后，会一次返回包装、缝制、染色、织造、原材料等生产阶段明细，分析时按生产阶段归类每一行：

```text
包装成品 (单位成本.物料编码；投入产出查询入参)
  |
  +- 包装阶段 (剔除缝制成品)
  |
  +- 缝制阶段 (剔除毛坯)
  |
  +- 染色阶段 (剔除白坯)
  |
  +- 织造阶段 (剔除白坯等下一层半成品，本阶段仅含织造加工费/人工等)
  |
  +- 原材料阶段 (核算要素名称=原料，原料/纱线/其他原料等最终原料成本，无下一层)
  |
  +- 存货明细 (对异常材料编码查价格流水)
```

`所属工段` 字段的标准取值为 `包装 / 缝制 / 染色 / 织造 / 原材料` 五种，脚本应作为有效工段识别。原料不再混入织造工段，而是单列"原材料"工段。

### 阶段净成本口径（强制）

成本结构分析必须按单阶段净成本归集，不能把下一层半成品重复计入当前工段成本。

| 阶段 | 当前查询中需要剔除的下一层成本 | 本阶段应计入的成本 |
|------|-------------------------------|--------------------|
| 包装阶段 | 缝制成品 | 包装辅料、公共包装辅料、包装直接人工、制造费用、加工费等 |
| 缝制阶段 | 毛坯 | 缝制辅料、缝制人工、缝制制造费用、缝制加工费、委外加工费等 |
| 染色阶段 | 白坯 | 染色加工费、染色人工、染色制造费用、染化料等 |
| 织造阶段 | 白坯 / 毛坯 / 下一层半成品 | 织造人工、织造制造费用、织造加工费等；**原料/纱线不再计入织造**，而是单列"原材料"工段 |
| 原材料阶段 | 无下一层 | 原料、纱线、其他原料等成本本身，结合存货价格流水分析单价影响 |

阶段净成本计算公式：

```text
本阶段净成本 = 本层投入产出金额合计 - 下一层半成品/原料金额
```

报告必须同时列出：本层投入产出总额、剔除的下一层金额、本阶段净成本、本阶段净成本占订单完工成本比例。

### 成本结构占比口径（强制）

**单位成本字段不足以支撑成本结构占比分析**。单位成本仅返回包装层自身字段（包装辅料、包装直接人工、包装制造费用等），下游工段（缝制、染色、织造、原材料）的金额全部合并在"未分类"中。这是错误做法，**严禁**在成本结构占比中把下游工段全部归为"未分类"。

正确的成本结构占比必须基于**投入产出数据逐级展开**：

1. 以包装成品物料编码为起点，按 carry 链向下游追踪：
   ```
   包装（物料=410141198）→ 缝制成品 → 缝制（物料=310140644）→ 毛坯 → 染色 → 白坯/坯布 → 织造（物料=210140482）→ 原材料（物料=210140482）
   ```
2. 每个工段按上级 carry 金额 / 本工段 stage_total 计算折算系数。
3. **carry 行（下一层半成品）不计入当前阶段成本项目**，它们代表向下游转移的价值；下游工段展开后自然覆盖。
4. 非 carry 行按"核算要素名称"映射到五大成本项目：原材料、辅料、直接人工、制造费用、外协加工费。
5. 链路断裂时，缺失工段跳过，下游工段使用最后一个有效折算系数（`last_scale`）兜底，**不再使用 1.0**。
6. **未追溯半成品 = 完工成本 - 已分类合计**，反映因数据缺失未能展开到成本项目的金额（如染色缺失时，织造/原材料已展开，但染色自身成本无法追溯，差额归入未追溯半成品）。

成本结构占比各项目之和必须等于 100%（以完工成本为分母）。若出现显著偏差，说明折算系数或 carry 剔除逻辑有误，必须排查。

### 成品单价口径

阶段成品单价用于查看产品做到该阶段时的综合单价，包含子工段成本；不要用阶段成品单价表进行成本项目剔除。

一个订单存在多个包装成品时，阶段成品单价表必须展示“上级产品”，否则无法判断缝制成品、毛坯分别对应哪个上级成品。

当上级产品领用的半成品金额与该半成品自身投入产出明细总额不一致时：

- 成品单价分析以本阶段明细为准，显示本阶段金额和本阶段单价。
- 同时展示上级领用金额、上级领用单价和差异金额，用于解释口径差异。
- 成本项目标准占比仍按上级实际领用金额折算，确保单个订单或单个包装成品的成本闭合。

### 成本追溯终止条件

以下任一情况说明投入产出链路不完整，并在报告中标记影响：

- 查询无结果，`data` 数组为空。
- 返回数据缺少生产阶段归类字段，无法按最新口径分析。
- 返回结果缺少包装、缝制、染色、织造、原材料中的某个生产阶段。
- 下一层材料编码为空或与当前层相同，存在循环引用风险。
- 继续追溯已不能解释当前异常，差异已被前面层级覆盖。
- **链路断裂**：某上游工段（最常见是染色）未取到明细，导致下游工段（织造/原材料）无法按上级领用金额折算。

如果返回结果缺少应有生产阶段，例如缺少某一生产阶段明细，必须在报告中标记为”该阶段未取到投入产出明细，可能为委外生产或当前报表未返回该阶段”。

### 链路断裂与多链路计算

由于标准链路是 包装 → 缝制 → 染色 → 织造 → 原材料 多层半成品流转，**任一上游工段缺失都会阻断下游折算**。当检测到链路断裂时，按以下多链路策略处理：

1. **链路断裂检测**：沿 carry 链逐级检查，若某工段无数据则标记为”未取到”，触发链路断裂。
2. **断裂后兜底**：缺失工段跳过，下游工段使用**最后一个有效折算系数**（`last_scale`）兜底，不再按 1.0 计入。
   - 例如：染色缺失时，缝制折算系数为 0.1099，则织造/原材料也按 0.1099 折算。
   - 兜底后的成本仍可能因多产品共用工段数据而存在偏差，报告需注明”含 last_scale 兜底口径的估算部分”。
3. **直接取值标签**仍只对”直接父级工段未取到”的工段使用（不级联）：
   - 染色未取到 → 织造 标”直接取值”（折算系数 = last_scale）。
   - 织造未取到 → 原材料 标”直接取值”（折算系数 = last_scale）。
   - 其余更深层级工段在状态表里标”已取到（last_scale 兜底）”。
4. **染色缺失**（最常见）：织造工段找不到白坯/毛坯作为上级半成品，按上级领用折算的链路中断。此时：
   - 染色阶段标记为”未取到”，并提示”可能为委外生产或当前报表未返回该阶段”。
   - 织造工段改为”直接取值”：使用本层 `stage_total` × last_scale 折算，不再做父级折算系数运算。
   - 原材料工段保持”已取到（last_scale 兜底）”标签，按 last_scale 折算后归属到”原材料”成本项目。
   - 报告必须明确说明”染色工段未取到，织造/原材料采用 last_scale 兜底”。
5. **织造缺失**（少数情况）：原材料标”直接取值”，按 last_scale 折算。
6. **缝制缺失**：染色标”直接取值”，织造/原材料按 last_scale 兜底。
7. **包装缺失**：报告顶部应明确”投入产出无包装成品明细，本次不计算阶段净成本”，所有下游工段都按 last_scale 兜底。

**多链路 last_scale 兜底口径**：

```text
当上游工段缺失导致下游工段无父级折算系数时：
  下游工段折算后金额 = 下游工段 stage_total × last_scale（最后一个有效折算系数）
  下游工段本阶段净成本 = 下游工段折算后金额 - 下一层 carry 金额 × last_scale
  成本项目归集按上述口径累加
```

脚本必须在”生产阶段取数状态”表中分别列”已取到 / 直接取值 / 未取到 / last_scale 兜底”四种状态，并标注哪些工段因上游断裂按 last_scale 兜底；不得把折算异常值（如 0 或负数）当作正常值。**不要把级联兜底工段都误标为”直接取值”**，”直接取值”是只对”直接父级为未取到”的工段使用的标签。

## 分析主流程


1. 读取 `gross-margin-detail-command.md`，确认取数工具、参数、区间传参规则和字段口径。
2. 用单位成本按会计区间或订单号取数，校验订单收入、成本、单位成本、毛利和毛利率。
3. 用包装成品的物料编码查询一次投入产出，获取包装、缝制、染色、织造、原材料等工段明细。
4. 按生产阶段分组，分别计算包装、缝制、染色、织造、原材料的阶段净成本；缺少生产阶段归类字段时停止并说明数据结构异常。
5. **检查链路完整性**：若某上游工段（如染色）缺失，对下游工段改用"直接取值"口径，不再做父级折算系数运算，并在报告与表中明确"链路断裂 / 直接取值"。
6. **输出链路追溯图**：以树形/链式结构展示从包装成品到原材料的完整追溯链路，每个节点标注状态（已取到/未取到/直接取值/兜底）、物料编码、carry 指向、金额和折算系数。链路断裂时必须明确标注断裂位置。
7. 按阶段净成本口径累计成本项目标准占比，原料单列为"原材料"工段，不再混入织造。
8. 对成本占比异常、单价异常或金额占比高的材料，查询存货明细价格流水，分析价格波动影响。
9. 读取 `gross-margin-detail-calculation.md`，用内置脚本或可靠计算工具完成阶段净成本、成本项目标准占比、异常金额和毛利率影响测算。
10. 读取 `gross-margin-detail-quality.md`，按报告规则输出最终分析报告。

## 输出要求

- 所有分析结论必须基于实际取数结果；缺字段、空结果、权限错误、取数中断必须明确标记。
- 成本项目标准占比必须使用阶段净成本折算后的结果，标准五项为原材料、辅料、直接人工、制造费用、外协加工费；未追溯半成品和未分类成本必须单列。
- 阶段净成本表是成本归属依据，阶段成品单价表只用于查看做到该阶段时的综合单价，两张表不得混用。
- 报告中的每个金额、占比、单价都必须能追溯到单位成本、投入产出或存货明细的实际返回数据。
- 建议必须绑定异常项和数据证据，不输出泛泛建议。

完整异常规则和报告模板见 `gross-margin-detail-quality.md`。
