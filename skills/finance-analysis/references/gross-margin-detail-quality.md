# 毛利率明细报告质量规则

## 一、异常识别

以下风险信号必须绑定数据证据。

### 亏损 / 低毛利订单

| 类型 | 识别标准 | 常见原因 |
|------|----------|----------|
| 亏损订单 | 毛利率 < 0 | 原材料涨价未调价、订单量过小、工艺复杂、外协费高、定价问题 |
| 低毛利订单 | 毛利率 0%~10%，或同一客户/物料持续偏低 | 半成品成本高、辅料/人工/制造费用压缩空间不足 |

亏损订单重点检查：完工成本是否异常偏高、是否小批量导致单位成本高、成本项目是否存在负数。

### 成本结构异常

成本分类占比超出以下区间时必须标记：

- 原材料 > 35%：原料涨价或耗量超耗
- 辅料 > 15%：包装冗余或辅料单价偏高
- 直接人工 > 40%：工序工价偏高或产量不足
- 制造费用 > 25%：分摊口径异常或产量规模不足
- 外协加工费 > 10%：外发价格偏高或自制/外协边界不合理

### 投入产出异常

- 单材料占完工成本 > 20%
- 同一材料不同期间单价差异大
- 实际耗量 > BOM 定额 × 完工产量
- 负数量/负金额（数据异常或红字冲销）
- 同一材料多行价格差异大（批次成本不一致）

### 存货价格异常

- 单价高于同期间均价，或达同期均价 2 倍以上
- 金额大但数量小（可能计量单位错误）
- 单据类型异常集中（非正常采购/生产入库混合）
- 月度加权均价波动大

### 毛利率波动

- 同一物料在不同订单间毛利率差异 > 10 个百分点
- 同一客户不同期间毛利率波动明显
- 排查：产量差异、原材料批次成本差异、价格策略差异

### 数据一致性校验

- 毛利 ≈ 销售无税金额 - 完工成本
- 毛利率 ≈ 毛利 / 销售无税金额
- 单位成本 ≈ 完工成本 / 完工产量
- 投入产出金额合计应与单位成本对应字段可解释
- 存货明细金额合计应 ≈ 主数量 × 单价

发现不一致时标注原因：四舍五入误差、数据导出问题、口径差异等。

## 二、核心计算规则

### 单物料分析规则

用户指定包装成品编码时：
- 单位成本只保留该包装成品，同订单其他成品不得混入经营结果、成本占比或阶段表
- 调用 `analyze_cost_structure.py` 时必须传入 `--material <编码>`
- 如需对比同订单其他成品，单独列为"同订单对比"，不得混入当前物料成本结构

### 阶段净成本规则

阶段净成本必须来自投入产出逐层剔除，**严禁用单位成本字段反推**。

| 阶段 | 净成本公式 |
|------|-----------|
| 包装 | 包装投入产出总额 - 缝制成品领用金额 |
| 缝制 | 缝制投入产出总额 × 折算系数 - 毛坯金额 × 折算系数 |
| 染色 | 染色投入产出总额 × 折算系数 - 白坯金额 × 折算系数 |
| 织造 | 织造投入产出总额 × 折算系数 - 下一层半成品金额 × 折算系数（不再剔除原料） |
| 原材料 | 原材料投入产出总额 × 折算系数（无下一层，不再剔除） |

- 链路断裂时：下游工段改用直接取值，折算系数 = `last_scale`，本阶段净成本 = stage_total × last_scale - 下一层 carry 金额 × last_scale
- **阶段净成本表**与**阶段成品单价表**用途不同，不得混用

### 包装层与缝制层金额差异

包装投入产出中的"缝制成品"金额 ≠ 缝制成品自身投入产出合计，报告必须同时展示：
- 上级领用单价、上级领用金额
- 本阶段单价、本阶段金额
- 差异金额 = 本阶段金额 - 上级领用金额
- 取价口径：成品单价分析以本阶段明细为准；成本项目标准占比按上级实际领用金额折算，确保成本闭合

禁止只展示一个口径而不说明差异。

### 链路异常处理（取数异常 / 未追溯半成品）

投入产出一次返回所有阶段明细，标准阶段为：包装、缝制、染色、织造、原材料。任一阶段缺失即为"取数异常"，必须：

1. **未追溯半成品单列**：`未追溯半成品 = 完工成本 - Σ(五大成本项目金额)`，不得归入原材料、辅料、人工、制造费用、外协加工费
2. **不得直接判断缺失阶段成本高低**，只能说明数据未支持拆分
3. **下游工段状态标注**：
   - 直接父级缺失的工段 → "直接取值"（折算系数 = last_scale）
   - 更深层工段 → "已取到（last_scale 兜底）"
   - 不得把下游折算 0 作为正常值展示
4. **建议指向**：核查是否委外生产，或检查取数范围、物料编码、会计区间

报告必须包含生产阶段取数状态表：

| 生产阶段 | 取数结果 | 影响 |
|----------|----------|------|
| 包装 | 已取到 | 可分析包装净成本 |
| 缝制 | 已取到 | 可分析缝制净成本 |
| 染色 | 未取到 | 该阶段无投入产出明细，可能为委外生产 |
| 织造 | 直接取值 | 因染色缺失使用直接取值（折算系数 = last_scale） |
| 原材料 | 已取到（last_scale 兜底） | 因染色缺失无父级折算，按 last_scale 兜底 |

### 成本项目标准占比规则

- **必须基于投入产出数据逐级展开**，严禁使用单位成本字段反推
- 标准五项：原材料、辅料、直接人工、制造费用、外协加工费
- carry 行（缝制成品、毛坯、白坯、坯布等）**不计入任何成本项目**
- 未追溯半成品和未分类成本必须单列
- 各成本项目之和 + 未追溯半成品 = 完工成本

### 原材料工段规则

- `所属工段 = 原材料` 是独立工段，对应原料 / 纱线 / 其他原料等最终原料成本
- 无下一层，不做 carry 剔除，金额直接归入"原材料"成本项目
- 同一订单中应与单位成本中"其他原料-50010199"等字段口径接近，差异大时需说明
- 织造工段剔除范围改为白坯/毛坯等半成品，不再剔除原料/纱线

## 三、报告输出规范

### 表达要求

- 正文使用中文业务名称（单位成本、投入产出、存货明细），禁止暴露 MCP 工具名或临时文件名
- 建议必须绑定异常项和数据证据，例如"外协加工费 12.00%，高于 0%-10% 区间"
- 无对比数据时不生成对比结论

### 报告结构

```text
## 毛利率明细分析报告

### 1. 数据范围
- 用户ID、组织、会计区间、订单号
- 查询记录数（单位成本 / 投入产出 / 存货明细各 N 条）
- 缺失字段说明

### 2. 经营结果
- 销售无税金额、完工成本、毛利、毛利率（含评级）、盈亏判断
- 同比/环比（有可比数据时）

### 3. 单位成本校验
- 完工产量、单位成本、销售单价(无税)、毛利率校验
- 不一致项列示

### 4. 成本结构分析
| 成本项目 | 金额 | 占比 | 标准占比 | 状态 |
| 原材料 | ... | ...% | 30% | 正常/偏高/偏低 |
| 辅料 | ... | ...% | 10% | 正常/偏高/偏低 |
| 直接人工 | ... | ...% | 35% | 正常/偏高/偏低 |
| 制造费用 | ... | ...% | 20% | 正常/偏高/偏低 |
| 外协加工费 | ... | ...% | 5% | 正常/偏高/偏低 |
| 未追溯半成品 | ... | ...% | - | 数据缺失 |

注：占比基于投入产出逐级展开。未追溯半成品 = 完工成本 - 已分类合计。

### 5. 投入产出链路追溯
树形结构展示，节点标注：
- 状态：✓ 已取到 / ⚠ 直接取值或兜底 / ✗ 未取到
- 物料编码及名称、carry 指向、本层金额、折算系数

示例：
包装成品: 410141198 CA473包装男平角裤
  ✓ 包装: 410141198 → 310140644 | 金额: 38,351,524.00
    ✓ 缝制: 310140644 → 252140485 | 金额: 281,619,015.00 | 折算: 0.1099
      ⚠ 织造: 210140482 | 金额: 96,596,567.00 | 折算: 0.1099 (直接取值)
        ⚠ 原材料: 210140482 | 金额: 71,774,254.00 | 折算: 0.1099 (last_scale兜底)

### 6. 折算率计算规则
报告必须展示各阶段折算率的计算公式和结果，让用户能复核数据来源。

| 阶段 | 计算公式 | 结果 | 说明 |
|------|----------|------|------|
| 包装 | 根节点，不折算 | 1.0000 | 起点 |
| 缝制 | 包装中缝制成品 carry / 缝制工段总额 | 0.1099 | 上级 carry ÷ 本工段总额 |
| 织造 | 染色缺失，last_scale = 0.1099 | 0.1099 | 直接取值（父级未取到） |
| 原材料 | 染色缺失，last_scale = 0.1099 | 0.1099 | last_scale 兜底 |

> 折算率含义：上级包装成品对下游各工段成本的"认领比例"。例如缝制折算率 0.1099 表示缝制工段总成本中，仅有 10.99% 归因于当前这个产品。

### 7. 阶段成品单价与阶段净成本
- 阶段成品单价表（含上级领用 vs 本阶段对比、差异金额）
- 阶段净成本表（本层总额、剔除下一层、净成本、占完工成本比例）

### 7. 存货价格分析
仅对异常或高影响材料展开：会计期间、单据类型、数量、单价、金额、vs 均价

### 8. 异常原因汇总
| 异常项 | 影响金额 | 毛利率影响 | 证据字段 | 计算口径 |

### 9. 优化建议
- 物料采购/单价管控
- 生产耗量管控
- 成本结构优化
- 订单报价建议（最低售价测算）

### 10. 数据质量说明
- 有效/无效记录数、数据异常、取数异常/生产阶段缺失
```

若需对公司整体毛利率提出建议，先通过综合查询获取区间整体数据聚合分析，**禁止用单个订单直接推断整体结论**。

## 四、异常信号速查表

| 异常信号 | 建议方向 |
|----------|----------|
| 材料单价偏高 | 采购询价、供应商议价、替代物料评估、价格审批阈值、异常入库单复核 |
| 材料耗量偏高 | BOM/工艺定额复核、裁剪损耗管控、领料退料闭环、批次超耗追踪 |
| 辅料占比偏高 | 包装方案标准化、共用辅料复盘、吊牌/衣架/外箱等高额辅料替代或议价 |
| 人工占比偏高 | 工序工价复核、计件效率分析、小批量订单报价加价、瓶颈工序改善 |
| 制造费用偏高 | 费用分摊口径复核、产量规模影响分析、设备/水电/低耗异常排查 |
| 外协加工费偏高 | 外发价格复核、自制/外协边界评估、外协报价与质量返工联动分析 |
| 售价不足 | 更新报价模型，把材料价格、耗量、人工、制造费用、外协和目标毛利率纳入报价底线 |
