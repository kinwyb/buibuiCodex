# 毛利率明细取数说明

## 数据获取

使用 `boda` MCP 服务提供的三个工具获取成本明细数据：

| 数据 | MCP 工具 | 必填参数 |
|------|----------|----------|
| 单位成本结构 | `finance_analysis_unitCostStructure` | `orderCode` |
| 投入产出表 | `finance_analysis_inputOutput` | `orderCode`、`materialCode` |
| 存货明细帐 | `finance_analysis_inventoryLedger` | `materialCode` |

### 调用示例

参数以 JSON 传入：

```jsonc
// 1. 单位成本结构明细：按订单查询订单整体成本结构（未指定会计区间时不要传 startPeriod/endPeriod）
{ "orderCode": "<订单号>" }

// 2. 投入产出表明细：按订单和物料编码查询物料成本组成
{ "orderCode": "<订单号>", "materialCode": "410141198" }

// 3. 存货明细帐：按物料编码查询价格流水
{ "materialCode": "<物料编码>" }

// 4. 查询越南组织
{ "orderCode": "<订单号>", "org": "越南" }

// 5. 用户明确指定会计区间时，才传 startPeriod/endPeriod
{ "orderCode": "<订单号>", "startPeriod": "2026-04", "endPeriod": "2026-06" }
```

## 参数说明

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `startPeriod` | ❌ | 工具默认 | 开始会计区间，格式 `yyyy-MM`，例如 `2026-04`；仅用户明确指定区间时传入 |
| `endPeriod` | ❌ | 工具默认 | 结束会计区间，格式 `yyyy-MM`，例如 `2026-04`；仅用户明确指定区间时传入 |
| `orderCode` | 单位成本 / 投入产出必填 | - | 订单号，多个用逗号或中文逗号分隔 |
| `materialCode` | 投入产出 / 存货明细必填 | - | 物料编码，多个用逗号或中文逗号分隔 |
| `org` | ❌ | 义乌 | 组织信息，可选值：`义乌`、`越南` |

### 会计区间格式

格式为 `yyyy-MM`，例如 `2026-04`。查询时 `startPeriod` 和 `endPeriod` 可以不同以覆盖多个区间。

如果用户未明确财务区间/会计区间，调用工具时不要传 `startPeriod` 和 `endPeriod`，由工具使用默认区间；不要自行按当前日期计算月份。只有用户明确给出区间时，才按用户提供的 `yyyy-MM` 值传入。

## 输出格式

三个工具均返回 JSON 格式：

```json
{
  "columns": ["字段名1", "字段名2", "..."],
  "data": [
    {"字段名1": "值1", "字段名2": "值2", "...": "..."}
  ]
}
```

- `columns`：字段名列表，定义数据含义及读取顺序。
- `data`：数据数组，每个元素为一条记录。
- 空字符串 `""` 表示该字段无数据。
- 实际字段以工具返回的 `columns` 为准，不得编造缺失字段。

| 人工 | 直接人工-500110、间接人工-510105、福利费-510106、五险一金-510108、劳务费-510120 | 人工成本明细 |
| 制造费用 | 折旧费-510101、水费-510103、电费-510128、修理费-510109、低值易耗品领用摊销-510115、汇总其他-510199 | 制造费用明细 |
| 外协 | 加工费-510110 | 外协加工费 |

### 投入产出

| 字段 | 说明 |
|------|------|
| 组织编码、组织名称 | 组织信息 |
| 物料编码、物料名称 | 查询的产成品/半成品编码 |
| 订单号 | 关联订单 |
| 所属工段 | 内部阶段归类字段，取值为 `包装`、`缝制`、`染色`、`织造`、`原材料` 五种；报告中表述为”生产阶段”，不要直接展示字段名。`原材料` 表示该行核算要素为原料/纱线等最终原料成本，是独立工段，不再混入织造阶段 |

| 字段 | 说明 |
|------|------|

| 组织编码、组织名称 | 组织信息 |

## 取数顺序

1. 先查单位成本，获取包装成品物料编码、完工成本、完工产量、销售金额、毛利率。
2. 用包装成品物料编码查一次投入产出，返回结果会包含包装、缝制、染色、织造、原材料等生产阶段明细。
3. **检查生产阶段完整性**：按 包装 → 缝制 → 染色 → 织造 → 原材料 的顺序检查是否每个工段都有数据。识别哪些工段”未取到”，哪些工段”已取到”。
4. **识别链路断裂**：若某上游工段（如染色）”未取到”，其下游所有工段（织造、原材料）按”直接取值”口径处理，不再做父级折算。
5. 按生产阶段分组计算阶段净成本：包装剔除缝制成品，缝制剔除毛坯，染色剔除白坯，织造剔除白坯/毛坯等下一层半成品，原材料不再剔除。
6. 如果包装、缝制、染色、织造、原材料中的某个阶段没有返回明细，在报告中标记”该阶段未取到投入产出明细，可能为委外生产或当前报表未返回该阶段”。
7. 对成本占比异常、单价异常或金额占比高的材料，查存货明细价格流水。
